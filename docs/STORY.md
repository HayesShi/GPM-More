# 关系信息的前向使用与学习反馈

> 有用的关系信息，应该在多大程度上改变生成它的共享表示？

GPM-More 围绕这个问题组织模型、干预与实验。我们以 GPM 为基础，用跨 walk 相位关系 Token 补充普通 Pattern 表示，并将关系信息的前向使用与它对共享编码器的反向反馈分别控制。研究的核心是同一预测任务内部的路径级学习反馈。

## 共享表示中的两种要求

GPM 从随机游走提取 Pattern，编码每条路径，再聚合这些表示进行预测。普通 Pattern 可以表达局部内容；派生关系还可以表达这些路径在原图中如何对应，例如不同路径是否访问了同一个节点。

本项目的 `raw_sum` 关系算子读取同一次路径编码中、池化前的上下文表示。它按原图节点身份对齐不同 walk 的访问，再用固定相位的双线性配对形成一个有内容的关系 Token。普通 Token 与关系 Token 共同进入外层 Transformer。

两条路径读取同一套上下文，也通过同一个任务损失改变它。端到端训练因而同时协调两种表示要求：哪些局部内容应被保留，以及哪些跨路径对应关系应被强化。关系内容是否值得用于预测，与这条关系路径产生的更新是否适合共享编码器，是可以分别检验的问题。

## 两类干预揭示了区别

前向干预固定权重与普通 Pattern Token，仅改变关系 Token 的内容。在保留 Token 范数、按路径碰撞程度分组置换方向的实验中，完整训练终点模型的 ArtNet 验证 R² 从 0.464124 降至 0.362450。这支持模型使用了与当前节点对应的关系内容；它尚不能将所有变化唯一归因于某一种图语义。

反向干预保留关系 Token 的前向数值，只停止关系路径向共享表示传回梯度。ArtNet 的同起点、单种子续训中，原始调度的最佳验证 R² 从 0.485170 提升到 0.499658。关系内容仍然参与预测，普通路径继续更新编码器，关系表示也随编码器变化重新计算。

两类结果共同支持一个训练原则：**模型可以充分使用派生关系，同时独立决定这种关系在多大程度上塑造共享表示。**

## 原则需要接受优化对照

停止反馈的收益受到学习率强烈调节。同一组从第 400 步继续到第 1000 步的实验中，额外学习率 ×0.1 得到最佳 R² 0.505139，叠加停止关系反馈得到 0.506518。附加收益缩小到 0.001379，说明更新尺度承担了这组改进中的较大部分。

这也要求我们精确解释路径交换。四个保存状态上的受控关系更新，会改善关系路径的预测，同时损害普通路径；然而两条路径共同变化后的验证误差仍然下降。局部路径牵连确实存在，它并不自动等于净损害。即使两条路径的预测变化完全可加，平方损失也会产生交叉项，不能仅凭损失交互推断复杂的非线性冲突。

因此，本项目研究反馈耦合，不预设关系梯度普遍有害，也不用梯度余弦直接定义更新的好坏。

## 将反馈变为独立变量

设共享上下文为 $h=f_\theta(x)$，普通路径为 $P(h)$，关系路径为 $R_\phi(h)$。公开实现把反馈控制放在关系算子的输入：

$$
\widetilde h_R=\operatorname{sg}(h)+\alpha\bigl(h-\operatorname{sg}(h)\bigr).
$$

前向始终有 $\widetilde h_R=h$。当 $\alpha$ 作为固定或预定调度的控制量时，共享编码器梯度为

$$
\nabla_\theta\mathcal L=g_P+\alpha g_R.
$$

关系算子内部若有可训练参数 $\phi$，它们仍获得正常梯度。`raw_sum` 的核心相位收缩本身没有可训练参数，因此旧实验中的关系输出 detach 与这里的输入控制，对所研究共享路径具有相同的停止效果。推理阶段始终使用完整关系信息。

## 一个没有被保留的实现

反馈作用随批次变化，使“每步选择完整反馈或停止反馈”成为自然的候选。我们从同一参数与 Adam 状态生成两个真实更新，用另一批训练根节点上的一步 MSE 选择候选，再提交完整的权重和优化器状态。

这个规则在 ArtNet 第 600 至 800 步的匹配实验中，仅比固定停止反馈多 0.000096 R²。选择探针与另一批不参与选择的训练探针，对哪个候选更好的判断只有 49.5% 一致。选择集上的即时优势没有稳定转移，因而该控制器未被纳入当前方法。

这一结果把原则与实现区分开来：反馈可以独立控制，但当前小型探针的一步收益不足以给出有效的控制规则。

## 当前方法与研究结论

当前代码保留 GPM 的主要计算流程、跨 walk 相位关系 Token，以及前向不变的反馈控制接口。已有简单训练版本采用后期学习率控制与停止关系反馈。固定强度和预定调度是清楚、可检验的选择；条件探针选择保留为负结果。

本项目已经支持“关系内容的使用价值与其学习反馈作用可被实验性地区分”。进一步的方法贡献，需要在合理学习率配置下获得可重复的附加价值，并解释它如何改变两条路径的共同学习。当前归档结果来自 ArtNet 的匹配机制实验，不能视为已经超过 GPM 或 G²PM 的标准基准主表。
