## 活动前向与历史实现核对

使用同一份历史 `raw_sum256` 第600步活动权重，在 CPU 上比较旧实现与本仓库实现。输入为三个训练根节点，分别使用4、8、12、16条固定 walk，不读取标签或计算任务指标。

| Walk 数量 | 预测最大绝对误差 | 节点表示最大绝对误差 | 关系 Token 最大绝对误差 |
|---|---:|---:|---:|
| 4 | 0 | 0 | 0 |
| 8 | 0 | 0 | 0 |
| 12 | 0 | 0 | 0 |
| 16 | 0 | 0 | 0 |

每组的完整反馈与停止反馈前向也逐比特相同。导入器明确忽略42个未参与活动前向的历史张量。机器可读记录见 [validation.json](../validation.json)。此检查依赖未公开的历史权重和缓存，公开仓库保留核对结果；它没有验证历史优化器轨迹的恢复。

## 可在仓库内重跑的检查

```bash
python -m pip install -e ".[dev,plots]"

```

测试覆盖：

- 反馈强度改变反向梯度，保持前向值；关系输入之后的可训练参数仍正常接收梯度。
- 相位关系收缩与显式配对一致，包括重复访问、重复 walk、单条 walk 及节点重编号。
- 历史活动权重的严格导入及允许忽略的非活动键。
- 训练/验证标签访问范围、缓存批次和分类标签约束。
- 命令行端到端连通：从小型工程图新采样 walk，经数据准备完成两步 CPU 训练，生成预测、指标与 checkpoint。它只验证入口连通，不计入真实任务结果。
- 从头连续训练与中断续训的精确一致性：模型、Adam、调度器、随机状态、历史记录及最佳权重。该检查使用小型 CPU 工程输入，包含 dropout、walk预算切换、反馈切换和后期学习率变化。
