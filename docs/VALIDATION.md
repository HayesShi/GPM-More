## CUDA 配对训练验证

初次自动搜索中，固定随机种子仍出现反馈切换前的训练分叉。首步数值差异约为10⁻⁷量级，后续被训练放大；该轮结果已留作诊断并排除配置选择。

启用确定性算法与cuBLAS工作空间设置后，在本机RTX 4060 Laptop GPU上分别对ArtNet-views和Tolokers-2执行完整反馈、后期停止反馈的独立进程核验。两组均使用seed 0、1000步调度，并运行至第400步；停止反馈从第401步才生效。

两数据集的第400步模型权重、AdamW状态、调度器、随机状态及训练历史逐项相同；0、50、100、…、400步的验证预测也完全相同。模型、优化器和预测的最大绝对差均为0。检查只验证本机配对训练的一致性，不参与超参数选择；正式搜索使用单独的新目录。机器可读结果保存在 [validation.json](../validation.json)。

## 活动前向与历史实现核对

使用同一份历史 `raw_sum256` 第600步活动权重，在 CPU 上比较旧实现与本仓库实现。输入为三个训练根节点，分别使用4、8、12、16条固定 walk，不读取标签或计算任务指标。

| Walk 数量 | 预测最大绝对误差 | 节点表示最大绝对误差 | 关系 Token 最大绝对误差 |
|---|---:|---:|---:|
| 4 | 0 | 0 | 0 |
| 8 | 0 | 0 | 0 |
| 12 | 0 | 0 | 0 |
| 16 | 0 | 0 | 0 |

每组的完整反馈与停止反馈前向也逐比特相同。导入器明确忽略42个未参与活动前向的历史张量。机器可读记录见 [validation.json](../validation.json)。此检查依赖未公开的历史权重和缓存，公开仓库保留核对结果；它没有验证历史优化器轨迹的恢复。
